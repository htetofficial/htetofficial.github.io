# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or privacy issue in the **Htet Official** website or its companion applications (Android APK / macOS / Windows), please do **not** open a public issue.

Instead, report it privately through one of the following channels:

- **GitHub Private Vulnerability Reporting:** Use the *"Report a vulnerability"* button under the **Security** tab of this repository.
- **Email:** `htethtet2025ideahub@gmail.com`
- **Telegram:** [@htetmmofficial](https://t.me/htetmmofficial)

Please include a clear description of the issue and steps to reproduce it. We will review and respond as soon as possible.
